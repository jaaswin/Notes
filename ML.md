# Machine Learning (ML)

## 1. Introduction

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn from data and make decisions or predictions without being explicitly programmed for every task.

In simple words, Machine Learning allows computers to learn from past experiences (data) and improve their performance automatically.

Example:

- When we watch videos on YouTube, it recommends similar videos based on our watching history.
- Gmail identifies spam emails automatically.
- Online shopping websites recommend products based on previous purchases.

## 2. How Machine Learning Works

### 1. Supervised Learning

Supervised Learning is a type of machine learning in which the computer learns using labelled data.

Labelled data means the input data is already provided with the correct output.

Example:

- Input: House size, number of rooms and location.
- Output: House price.

The computer learns from previous examples and predicts the price of a new house.

Applications:

- Email spam detection.
- House price prediction.
- Weather forecasting.
- Disease prediction.

### 2. Unsupervised Learning

Unsupervised Learning is a type of machine learning in which the computer learns from unlabelled data.

The computer identifies hidden patterns and groups similar data without knowing the correct output.

Example:

A shopping website groups customers based on their shopping behaviour.

- Group 1: Customers who buy clothes.
- Group 2: Customers who buy electronic products.
- Group 3: Customers who buy groceries.

Applications:

- Customer segmentation.
- Market analysis.
- Grouping similar documents.
- Fraud detection.

### 3. Semi-Supervised Learning

Semi-Supervised Learning uses both labelled and unlabelled data.

A small amount of labelled data and a large amount of unlabelled data are used to train the model.

Example:

In image recognition, a computer is trained using:

- 100 labelled animal images.
- 1,000 unlabelled animal images.

It uses both datasets to improve its learning.

Applications:

- Image classification.
- Speech recognition.
- Medical image analysis.

### 4. Reinforcement Learning

Reinforcement Learning is a type of machine learning in which an agent learns by interacting with its environment through rewards and penalties.

The system learns which actions are good and which actions are bad.

Example:

A robot learns to walk:

- If it moves correctly, it receives a reward.
- If it falls, it receives a penalty.
- By repeated practice, it learns to walk properly.

Applications:

- Robotics.
- Self-driving cars.
- Game playing.
- Industrial automation.

## 5. Advantages of Machine Learning

1. Reduces human effort.
2. Improves prediction accuracy.
3. Handles large amounts of data.
4. Automates repetitive tasks.
5. Helps in faster decision-making.
6. Improves performance through experience.

## 6. Disadvantages of Machine Learning

1. Requires large amounts of data.
2. Training models can be expensive.
3. Requires high computing power.
4. Incorrect data can produce incorrect results.
5. Some models are difficult to understand.
6. Data privacy and security issues may occur.

## 7. Difference Between Traditional Programming and Machine Learning

| Traditional Programming             | Machine Learning                     |
| ----------------------------------- | ------------------------------------ |
| Rules are written by programmers.   | Rules are learned from data.         |
| Requires explicit instructions.     | Learns patterns automatically.       |
| Output depends on programmed rules. | Output depends on the trained model. |
| Does not learn automatically.       | Can improve with more training data. |

## 8. Conclusion

Machine Learning is an important branch of Artificial Intelligence that allows computers to learn from data and make predictions or decisions without explicit programming for every task. It is widely used in healthcare, banking, education, robotics and many other fields.
